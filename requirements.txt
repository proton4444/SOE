# pyproject.toml is the source of truth for dependencies. This file kept a
# second, drifting copy of them -- it was missing bandit, mypy, ruff and build
# for long enough that a fresh environment could pass `pip install -r` and
# still not run the gates. It now installs the same sets by name.
#
#   pip install -r requirements.txt      (from the repository root)
#
# Engine only, without the web server or the tooling:
#
#   pip install .
#
# Regenerating the world map additionally needs the `map` extra (numpy,
# pillow, scipy, scikit-image). It is a build-time input, not a runtime one.
